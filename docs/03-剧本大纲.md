# 剧本大纲

## 左侧创作设置
主题、目标观众、叙述语气、故事目标紧凑排版。观众和语气有常用选项及自定义输入。历史框架、虚构内容、禁止内容分别为可增删、可折叠列表；历史框架来自用户确认的材料，不表示系统已独立验证。

## 右侧剧情
剧情详情可编辑标题、目标、具体发展、参与人物、前后关联及大致画作区域。下方展示该剧情自己的子叙事线索，每条只是一小段情节，不再要求拆分事件、动作和对白。每条叙事线索只能属于一个剧情，不能跨剧情共享；每个剧情至少有一条子线索。

## 生成子叙事线索
剧情详情以及「检查与发布」中的剧情待办均提供「一键生成子叙事线索 · 调用 LLM」。新增显式任务 `plot_clues`，target为剧情ID；使用当前剧情与已确认的资料、创作框架和人物生成通常1至3条短情节。

结果追加为草稿，不改写剧情正文，不覆盖已有线索，不自动确认，不自动启动知识或分镜生成。新线索归属于当前剧情；已有同名子线索不重复添加。若旧界面留下了指向其他剧情子线索的关联，生成时只整理当前剧情的草稿链接，原线索及其所属剧情保留。失败或输入过期时不应用结果，允许明确点击重试。也可手动添加并在简化编辑器中修改。

确认设置时的整套剧情生成仍可一次生成剧情与其子线索；重写整个剧情与仅生成子线索是两个独立按钮。

## 依赖与验收
剧情和子线索分别确认。子线索发布后，所属剧情、知识和分镜保留确认状态，通过版本提醒展示旧依据；不影响无关剧情。锁定、逐字引用校验和版本冲突保护继续保留。验收覆盖唯一归属、单段编辑、追加生成不改写、失败保稿及过期结果保护。
