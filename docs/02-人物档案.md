# 人物档案

文献对已明确在画中的人物提出单一、较明确的身份解释时，采用后可直接用身份称谓作标题；多个竞争解释或是否在场不明时保持保守。原称谓、推测性质及引文在“创作称谓依据”中保留，既有稳定角色ID与发布规则不变。旧数据不在打开时重新命名；按按钮整理后先展示建议，由用户采用。

## 布局
左侧滚动导航显示面部截图、姓名和资料确认标签；右侧编辑选中人物。标题为醒目的姓名与身份，资料状态在右上角。移出创作意图及历史边界。

## 人物资料
保留身份、经历、关系、简介及原文提及。只归纳输入的信息；缺失时说明未提供。创作者直接命名与史料姓名区别标记。已确认资料及画面绑定复用现有数据，不强制所有画中人物对应历史身份。

增加角色类型（具名人物／角色称谓／群体角色）和画中范围（画中／背景或作者／未知）。原文视觉身份提示关联引文，只作匹配依据建议；旧项目缺失字段显示未知，不自动补齐。称谓角色允许对应多个画中实例。群体角色在本页共用一份档案；画面实例使用“群体名(n)”区分，姓名选择仍关联同一个角色ID。

## 知识库
取消“角色知道什么”自由文本，改为静态线索绑定。没有已确认线索时禁用。LLM按人物身份、参与情况、线索内容建议绑定并给理由，用户增删后确认。原知识绑定保持不变；进入新版欣赏前，在下方入画角色设定中另外核对画中当时的可知时间。资料确认与知识确认独立；确认知识不重新生成关系线索。

## 确认与模型
首次确认人物资料会产生相关人物关系线索候选，按钮注明调用。后续发布人物改动后，依赖项继续可用，显示旧版本提醒，可单条或批量复核，不自动重生成。新知识建议不覆盖人工确认的绑定。

## 验收
面部截图回退、导航定位、简介与出处共享、资料和知识状态独立；同一人物可有多个画中实例，未命名实例不误拦截。

## 入画角色设定

人物与知识确认后，单人或批量生成角色提示词，修改性格预设、口吻与即时反应，核对档案及每条线索的当时可知／事后发生／待核对，再确认或一键确认本页。新体验只开放已有确认角色设定的人物，未准备其他角色不阻止使用。人设不进入视频依赖，重新生成先保留为建议。详见[字段、对话与引导规则](19-入画角色设定与线索引导.md)。
