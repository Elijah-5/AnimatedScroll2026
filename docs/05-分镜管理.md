# 分镜管理

每条具体线索固定一个分镜；文件夹不生成分镜，共享线索不重复建分镜。

## 设置与提示词
显示对应线索与剧情。用户选择参与人物并确认画作大致区域，可明确选择无人出镜。明确按钮确认设置并调用LLM生成：主体与动作、镜头运动、古画风格限制、起始画面、结束画面及完整文生视频提示词。生成结果待人工审核。此按钮只生成文字描述；原画参考与视频提交见下方独立视频区。

## 状态
待配置、待生成、生成失败、待确认、已确认、输入失效。配置与提示词分别记录输入指纹；改变人物或区域后，旧提示词不可确认。分镜先独立制作，不要求跨分镜连续衔接。

## 依赖与验收
依赖线索、参与人物及已确认知识。普通上游变化只产生版本提醒，旧提示词继续保留确认和使用能力。失败不丢设置，可显式重试；视频制作见下方独立视频区；制作提示词与提交视频分别由明确按钮触发。

## 独立分镜视频

视频以现有storyboardId关联线索，每条分镜独立生成，只消费有效确认版本及依赖。资料草稿不会进入请求。

先查看最终提示词，再编辑保存、勾选审核并生成。实际提交保存的完整字符串，不追加隐藏前后缀。原画和出场人物的已确认实例裁切作为参考，不强制实际首尾帧；首尾画面描述保留在文本中。

默认参数沿用同学代码：wan3.0-video、480P、5秒、有音频、无本地次数上限。按实际发送的完整文本、参考图内容及顺序、模型与参数去重和审核。普通资料或知识变化不撤销相同请求的审核；实际请求变化才需重新审核。旧视频保留播放、下载和选择入口，明确标注来源版本。

远端ID、输入快照、请求配置和任务状态持久化。重启只查询原远端任务；提交超时、连接中断或服务端不确定错误不会自动重提。明确失败的任务可以在重新审核后显式重试；下载失败只重试下载，不再生成视频。
