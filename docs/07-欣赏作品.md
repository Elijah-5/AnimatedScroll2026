# 欣赏作品：实时入画对话

顶栏「创作／欣赏作品」在同一标签切换，路由`#/experience`。欣赏页不显示制作侧栏、检查抽屉或待办banner；返回时恢复项目、制作页面、实体选择与滚动位置。刷新后按项目保存的制作位置返回；没有记录时返回概览。

## 人物与知识

画中每个已确认身份和档案的实例可单独选择。标签与人物轮廓在鼠标靠近时出现；点击后背景暗化，画作平移放大到人物上半身。点击背景、返回全景按钮或按Esc还原。轮廓由本地SlimSAM分割并缓存透明PNG，加载和失败状态明确显示。

下方按角色ID合并人物卡片，同群体多个实例共用一张卡片、角色知识与聊天记录，不按姓名合并不同人物。头像优先取已确认人物档案中的面部框，其次取确认画面实例中的面部框，否则取人物框上方约三分之一。画中实例继续保持各自的位置与轮廓。

新版可交谈人物的资料、知识绑定、依赖线索及入画角色设定须有效且已确认。知识尚未开放的人物可以聚焦观看，但不能发送问题；不要求宫人引路，不自动补齐未知身份。

只有点击「发送」才调用实时模型。模型仅接收本人物已确认资料、绑定线索、相关逐字依据及本人物会话历史；不接收完整剧本或其他人物聊天。新版默认画中事件当时，只取得角色设定确认的当时可知资料；事后与待核对内容不发送给实时模型。知识范围外回答不知情。

新版按段落显示实线资料复述、虚线已有研究推断与无框合理演绎，各段可展开依据；旧版回答不补造标签。服务端验证线索ID属于本人物；这不等于自动证明自然语言回答的每句话均正确，仍需观察实际模型质量。

聊天使用左右消息气泡，显示人物头像、称谓和发送时间；线索卡片位于回答下方，依据可单独展开。消息区独立滚动，阅读较早记录时不强制跳到底部。切换角色保留尚未发送的问题；同群体实例共享会话。只有明确发送或重试才调用对话模型，悬停、聚焦、换头像或生成本地轮廓均不调用远端API。

## 收集与观影

模型回答不自动记录线索。观众点击「记录线索」后解锁该线索对应的独立分镜，优先播放手动选择的视频，可使用明确标注版本的旧结果；同版新完成视频可加入当前会话，没有视频则显示该会话的确认分镜。

体验会话、消息和收集进度写入独立数据表，浏览器只保存会话标识。刷新恢复既有记录，不调用模型；改变相关确认内容后，旧会话继续使用固定快照并提示旧版本；明确重新开始才进入最新版。草稿编辑、项目改名和任务轮询不会重置体验。

发送请求有持久化去重，同一请求ID不会重复调用；失败保留问题，明确重试才创建新请求。服务重启将未完成回答标为中断，不自动重试。聊天和收集不会改写制作项目、确认状态或项目版本。

本地模型准备、缓存接口与验收范围见[欣赏页交互与本地抠图](17-欣赏页交互与本地抠图.md)。

## 角色与话题引导

连续三轮未触及未记录线索时给出选人与提问建议；整场体验共用计数，配置可在创作设置修改并确认。点击建议只聚焦并填问，仍须发送；关闭后等待新的阈值轮次。规则、版本兼容与接口见[入画角色设定与线索引导](19-入画角色设定与线索引导.md)。
