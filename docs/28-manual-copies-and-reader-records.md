# 手动创作副本、备份保留与体验记录

## 日常保存

创作中的修改继续自动保存到当前本机项目，网络失败保留输入。不会因为打开页面、切页或编辑而自动建立整库备份目录。原有依赖依据和审计历史继续使用无损压缩存储，不在本轮删除。

创作区顶栏增加 **保存副本**：点击后选择 **下载当前创作副本**，先等待当前编辑保存，再下载 ZIP。服务端仅使用临时文件发送，响应结束后删除；不会在 `data/` 留下一份又一份副本。上次交给浏览器下载的时间保存在浏览器的简短元数据中，不把整项目存进 localStorage。浏览器可能取消下载，界面明确提示用户确认下载文件已保存。

概览页在尚未保存副本，或上次下载超过一天且内容有变化时，显示小圆点提醒；不弹出强制确认，也不自动生成副本。

ZIP 包含当前草稿、审核记录、必要历史依据、可读取的画作／文献和已完成的本地视频。包含文件清单、大小和 SHA-256；缺失素材在清单中说明，不伪造补齐。不包含密钥配置、整库事件表、观众聊天或体验进度。包内允许保存尚未完成的草稿，不受人工审核门槛限制。解压后总量上限 1GB，项目 JSON 上限256MB；过大的视频需单独下载。

**从副本恢复** 接受本工具下载的 ZIP，校验项目与素材后建立独立项目。角色、线索和分镜 ID 保留在新项目内，素材用内容哈希命名，已有文件不被覆盖；视频恢复为已完成的本地结果，不重新提交远端任务。原项目及体验记录保留。无效 ZIP、越界路径、重复条目和校验失败均拒绝写入；恢复事务失败时回滚项目及本次新建文件。

接口：

- `GET /api/projects/{pid}/creation-copy?version=…`：只读下载；并发内容变化返回409，不增加制作版本或操作事件。
- `POST /api/creation-copies/restore`：multipart `file`，恢复为独立项目。

## 体验记录范围

按用户更正，长期体验记录包括聊天及其显示依据、线索触发／收集与时间。聊天仍保留原始提问时间，新增回答完成时间；线索被回答实际触及时用完成时间记录触发，观众明确点击记录线索时保存收集时间、角色与对应回答。重复发送和重复收集不重复增加记录，失败回答不触发线索。

`GET /api/projects/{pid}/experience/sessions/{sid}/records` 提供轻量记录读取，只读会话及聊天表，不读取完整制作项目、历史审计或准备轮廓。旧聊天缺少完成时间时标为旧请求时间；旧收集记录无法证明发生时间时返回 `null` 并标明未知，不补造时间。

当前体验使用的固定制作快照、原画和轮廓缓存仍按原规则复用，以便恢复旧体验和正确解释旧对话。每轮聊天只写聊天和进度，不额外复制项目、PDF、图片或视频，不重建体验。手动创作副本不带观众记录；维护用唯一完整恢复包保留实际数据库中的聊天与进度。

## 必要备份与清理

只保留一份最新、验证完整的维护恢复包，位于 `../merge-backups/recovery-…/`，包含源码、本机配置、当前数据库与素材。具体绝对路径、清理清单及释放字节数记录在 `.runtime/backup-retention.json`；源文件及逐表校验在恢复包的 `manifest.json`。

本轮保留点：`../merge-backups/recovery-20261102T002604Z/`。清理25份旧备份与专用临时副本，文件总量约57.3GiB；实际磁盘释放量取决于 APFS 共享块及快照。恢复包不重复包含 `models/` 权重缓存、依赖或构建产物，正式目录中的模型缓存保留。正式库仍有3个项目、234条历史事件、4个体验会话和17条聊天任务记录，逐表一致。

本次清理先等待运行任务和对话完成，正常停止后端，备份最新数据并逐表校验，再启动新版后端。接口检查通过后，才删除既有25份重复实施备份、旧的迁移前独立库，以及上一轮专用性能验收临时副本。不删除正式项目、聊天、体验进度、素材或真实验收资料。前端进程继续复用。

这项维护由显式命令触发，不定时运行：

```sh
# 只预览，不删除
.venv/bin/python scripts/retain_recovery_backup.py
# 明确执行维护：建立并校验最新恢复包、重载并清理旧备份
.venv/bin/python scripts/retain_recovery_backup.py --apply
```

后续日常创作使用手动下载副本，无需反复执行上述维护命令。旧文档中的已清理备份路径属于实施沿革；当前恢复点以 `.runtime/backup-retention.json` 为准。恢复整套服务前先正常停止服务，保留实施后的新增记录；从当前恢复包读取源码和 `data/`，依赖及模型缓存按 README 配置。旧代码不理解历史压缩引用时，仍需按第27章将当时最新库展开为兼容副本，不可直接用旧库覆盖新增聊天。

## 验证

383 项后端、57 项前端状态测试及构建通过。新增覆盖副本内容、下载不落地和不改制作版本、独立恢复、素材校验、缺失文件、异常回滚、线索时间与去重、旧时间不伪造，以及备份清理不处理未知目录／符号链接。浏览器在小型隔离项目完成“下载副本 → 从副本恢复 → 独立项目保留原内容”，未调用真实模型或视频服务。
