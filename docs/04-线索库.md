# 线索库

## 树结构
固定文化背景、人物关系、叙事线索三个根。中间节点是分类，叶节点是线索。按名称显示，颜色区分类型，支持增删、展开收起及移动，禁止分类循环。

## 文化背景与人物关系
保留概述、关联人物、细分内容、真实性分类、原文引用及推导说明。真实性边框仍按最开放成分展示：包含虚构即虚构，否则含推测即推测，否则有依据。选中轮廓与真实性含义分开。

## 叙事线索简化
编辑区只需短标题、唯一所属剧情和一小段情节，不展示关联人物复选列表或事件／动作／对白单元编辑器。人物从所属剧情继承。每条线索只属于一个剧情，不允许跨剧情共享。

新增 `content` 保存段落；保留单元素 `plotIds` 以兼容现有接口。旧线索打开时从原内容单元组合显示，不调用模型、不自动改写或丢弃引用；旧多剧情归属必须手动选择唯一剧情再保存。原有内容和依据可以折叠只读查看。

修改情节后按叙事创作保存，不自动当作史料原文；原单位内容与依据保留为legacyUnits及操作历史。原内容锁定时必须先明确解锁并保存，才能修改或重生成。

## 确认与依赖
确认线索后仍只创建一个对应分镜。原文引用审核继续保留。叙事线索发布改动后，所属剧情、知识及分镜继续可用，通过版本提醒展示差异并支持批量复核。改变所属剧情后，确认时更新两边的关联，不把线索隐式共享给其他剧情。
