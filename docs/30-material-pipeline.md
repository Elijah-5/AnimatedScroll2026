# 多来源资料整理与统一反馈

画作资料库默认展示整幅画的紧凑摘要：作品档案、画中人物、关系、背景与事件、研究判断、来源概况。详情和直接编辑按需展开，逐字依据在原文抽屉中回查。原始来源、版本及历史记录保留。

## 操作

1. 在资料来源中批量选择 PDF、文本或图片，也可以输入文本。默认整理所有来源，部分文献和页码选择在高级设置中。
2. 点击「整理资料／更新资料」。上传仅本地解析；扫描页须显式执行 OCR。按来源提取，复用内容相同的已完成批次；部分提取失败保留成功信息，并显示尚未覆盖的来源。
3. 在摘要面板查看核心内容，展开详情或对应原文。普通差异、互补、别名、缺失及 OCR 疑点不计入争议。只有同一对象、同一语境下双方有依据且不能同时成立的说法，才显示真实争议。
4. 可选择采用 A、采用 B、保留分歧，或用自然语言处理。未解决分歧不阻止创作，后续页面建议先处理；模型须保留不确定性。
5. 点击模块的「智能修改」，或勾选一个／多个条目，再使用同一智能修改面板发送方向。明确要求直接更新；不清楚时先追问。修改完成后可撤销，后续重叠修改会阻止撤销，其他条目的修改保留。

Overview 将完整制作流程画为可导航的流程图，并单独展示资料整理子流程；保持桌面横向布局（1280px 起），显示反馈回路与回查原文分支。打开、切页、选择、展开及保存均不调用模型。

## 数据与接口

权威资料仍在 material:main.draft.structured。summaryBlocks 是按内容指纹维护的阅读投影；summaryOverrides 记录明确反馈产生的模块概括。personRedirects、mergedNames 保留人物合并后的旧编号与称谓映射。原 conflicts 兼容记录不会仅因值不同被提升为真实矛盾；真实矛盾包含 kind=contradiction、共同 context、reason 和带 referenceIds 的双方 alternatives。

反馈接口：

- POST /api/projects/{id}/studio/feedback：version、requestId、target（kind=library/intent/plot/clue/character/persona/storyboard、section、itemIds、可选 fields/unitIds）、instruction；直接争议选择可传 resolution=current/candidate/keep_both。
- GET /api/projects/{id}/studio/feedback/{jobId}：status、progress、question、message、operationId。状态包括 queued/running/needs_input/completed/stale/failed/interrupted。
- POST /api/projects/{id}/studio/feedback/{operationId}/undo：仅回退该次操作，重叠编辑返回 409；重复撤销幂等。

资料库智能修改返回受约束的 update、merge_people、resolve_conflict、summarize 操作，资料库适配器验证作用范围、字段、人物关联和引文。没有依据的新判断保持创作者输入及 uncertain，不升级史料核验等级。人物合并更新当前人物陈述、关系和实例关联，保留旧 ID 重定向；既有剧情、视频及历史快照不重写。后续生成按重定向读取身份。

feedback_jobs 持久化请求、进度、局部变更和撤销保护，参与现有互斥任务与重启保护。前端网络失败重用未确认请求编号，成功后清除重试载荷。SQLite 与 MySQL 适配和显式迁移清单均包含该表；不自动执行 MySQL 迁移。

## 验证

后端回归使用模型替身，覆盖结构化人物合并、实例和关系更新、历史保留、局部撤销、同模块无关修改、重叠冲突、过期任务、幂等提交、追问、越界及无效引文拒绝、争议选择零模型调用、跨来源部分失败和相同正文的提取缓存复用。

执行完整 pytest、npm run test:ui、npm run build，并在独立临时数据库中检查1440×900、1920×1080 大屏布局、选择反馈作用范围、原文抽屉和 Overview 导航。技术验证不表示已核实文献的历史结论，未额外调用真实付费模型。


## 人物收敛与全站智能修改

资料库顺序为紧凑来源入口、默认展开的画作与画中人物、资料摘要。画作默认高度限制为 560px，保留缩放、框选、裁切与姓名对应。其他资料人物及补充候选默认折叠，不构成必填待确认项。

`people_policy` 是资料投影、自动角色采用、身份匹配及制作角色选择的共同准入规则。有明确画中依据的新人物和已有人工确认／剧情使用角色保留；单纯存在角色 ID、正文提及、同官职或同服饰不足以准入。背景信息、原文、关系及实例均保留。旧项目读取时仅计算投影；显式整理才能持久化安全归并。唐太宗／太宗等只有线索的称谓显示为可选分组，明确同人引文或同一已绑定实例才允许自动归并。群体与具体身影不强行合并。

搜索和范围筛选支持全选完整筛选结果（跨分页）、取消选择、加入画中人物、仅保留资料人物。确定性归类沿用反馈接口的 `peopleAction=include/exclude`；独立归并组使用 `merge_groups` 与 `groups`。这些批量操作不调用模型，可局部撤销；人工加入仅记录创作者决定，不修改文献证明等级。

资料库、剧本（含创作方向）、线索（含单元）、人物档案、独立对话设定及分镜共享「智能修改」面板与 `AppIcon name="ai"`。面板按项目／页面保存未发送输入，任务进度跨页保留。各内容类型适配器限制稳定条目及可改字段；不能改归属、知识权限、锁定项或视频状态。明确要求直接局部更新，意图不明则追问；关联内容只提示，不自动重生成。选中分镜修改只更新描述，不提交视频生成。

通用适配器回归覆盖六类内容的局部改写和撤销、锁定与越权拒绝、角色镜像同步；人物回归覆盖 130 位提及收敛、人工归类零模型调用、独立归并组、称谓歧义和群体分离。前端状态测试覆盖跨页全选和字段／单元选区身份。浏览器批量与撤销验收使用独立数据库副本，不修改原项目资料。
