# 人物框减遮挡与可视化线索树

## 操作

画作中的未选中框为 1px、30% 透明边线，无内部填色。悬停或选中只显示一个框外姓名，只有选中框显示调整手柄。重叠时按选中手柄、最近框边、较小包含框依次命中；右侧群体编号仍精确选择各个身影。

线索库使用从左向右的节点连线树：三类根分类、子分类、线索。初始折叠根分支，点击名称或加减号展开；搜索保留祖先路径，清空恢复原折叠状态。支持缩放、平移、适应视图及展开大图。名称、概述编辑不重新排列整树或重置视角。

在线索库将 `⋮⋮` 手柄拖入同类型分类，松手后保存归属并重新排列。根分类固定，不允许循环或跨根类型嵌套。右侧“移动到分类”使用同一树作为键盘可操作的替代入口；分类管理可新增子分类、改名及选择父分类。网络失败或冲突显示原因，图上临时位置恢复，后台不会留下部分移动。

人物档案的知识范围使用相同分类树。复选框和查看详情分别操作，分类支持全选、半选与数量显示。分支选择始终作用于全部可用后代，不受搜索过滤影响；旧失效绑定仍列出，可单独移除。人物页不提供全局分类拖动，不增加审核步骤；群体继续共用原角色知识。

## 实现与兼容

- 按需载入 `@vue-flow/core@1.48.2` 和 `@dagrejs/dagre@3.1.3`，树图代码独立分包；不使用运行时 CDN。授权声明见根目录 `THIRD_PARTY_NOTICES.md`。
- 开源来源：[Vue Flow](https://github.com/bcakmakoglu/vue-flow)、[官方自动布局示例](https://vueflow.dev/examples/layout/simple.html)。两页共用节点组件，模式为管理、知识勾选和目标分类选择。
- 数据继续使用原分类、线索 ID、`parentId` 与知识 `clueIds`，图上坐标不持久化为另一套关系。旧缺失分类或损坏层级显示“分类待整理”，不会丢弃内容或自动重分类。
- 分类复用 `PUT /api/projects/{pid}/studio/folders`；线索移动与知识勾选复用单位自动保存接口。服务端统一校验分类结构及移动，并保留项目并发校验、字段冲突保护和自动保存请求去重。
- 分类移动不改变事实、引文、剧情所属或知识绑定，不因展示用 `parentId` 改变而触发下游 outdated；旧审核依据中的该展示字段兼容忽略，不改写原审核历史。
- 无 SQL 迁移，不调用模型，不改变视频提交审核或体验快照。
