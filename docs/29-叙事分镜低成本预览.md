# 叙事分镜低成本预览

分镜管理新增生成范围：默认「仅叙事线索」，可切换全部线索；不删除旧分镜。勾选控制提示词及媒体的生成目标，最多三条媒体预览为一组。生成提示词仍是单独操作，查看、筛选、勾选和报价不调用付费生成服务。

## 使用

1. 准备并核对分镜的区域、人物和文字。
2. 勾选 1–3 条，选择低清视频、分镜图片或免费原画局部预览。
3. 点击「生成低成本预览 · 先查看费用」，查看模型、目标、时长、提示词、参考图数量及预算。
4. 明确提交后仅制作第一条。检查后选择通过才提交下一条；不通过则停止尚未提交的任务。通过的结果按内容指纹进入欣赏作品。

## 模型与费用

视频复用 AIHubMix Key，使用已核实的 `/ai/v1/videos` 协议：wan3.0-video、480P、5秒、generate_audio=false、prompt_extend=false。原画与已校准人物裁切作参考。

图片每次报价从公开目录和请求 Schema 核实参考图能力、输出单价和输入图片费用，排除无法计算上限的 token 计费模型。当前可核实的低价模型为 agnes-image-2.1-flash：输出 $0.01/张，参考图输入 $0.003/张。原生图片接口使用同步内联输出；账户原生媒体权限未开启时，可使用该模型已公布的 `/v1/images/edits` 兼容接口，以原画为单张参考。不猜测未公布的模型路径或参数。

跨项目共享本轮 **¥10** 上限。报价使用实时美元人民币汇率并预留25%余量；所有进行中及等待逐条检查的任务先占用预算。未提交就停止的任务释放预留；失败任务保守保留预留，不假设退款。没有自动重试、自动充值、付费语音或多版本抽卡。提交超时/状态不明阻止新的付费任务；已知远端任务只继续查询或下载。

这是一轮测试的持久预算，刷新和重启不会重置。报价15分钟过期，源内容变化须重新报价。最终费用以供应商账单为准，本地显示的是保守预算占用。

## 体验

点击「记录线索」保存收集后，画作按完整分镜区域聚焦，在画中打开讲解播放器。视频正常播放一次并保留末帧；图片缓慢推近。语音逐句朗读已审阅的线索原文，同步切换字幕，不新增讲解内容。优先使用设备本地中文语音，无可用语音或被浏览器阻止时保留文字及明确提示。

支持暂停、继续、重播、关闭和返回全景。切换讲解、人物或离开页面时停止前一段。刷新只恢复收集记录，不自动播放，不生成媒体。媒体指纹包含分镜、绑定线索、原画和人物参考；修改后的媒体不进入旧内容快照。已有视频、聊天与收集记录保留。

## 接口与持久化

- `POST /api/projects/{pid}/studio/generation-batches` 增加 `clueScope: narrative | all`，分镜页默认 narrative；初次生成及重新生成均在服务端检查目标范围。
- `GET /api/projects/{pid}/media-previews`：读取预览和共享预算。
- `POST .../media-previews/quote`：version、scope、storyboardIds（1–3条）、kind（video/image/crop）；只报价。
- `POST .../media-previews`：quoteId、requestId；校验当前依据、报价、去重及预算后建立逐条任务。
- `POST .../media-previews/{id}/review`：accepted，检查通过后提交下一条。
- `POST .../media-previews/{id}/resume`：仅查询/下载原任务。
- `GET .../media-previews/{id}/file`：本项目本地文件。

新增 media_preview_jobs / media_preview_quotes 表，纳入 SQLite / 可选 MySQL Schema 及迁移清单。文件保存在 data/media-previews；密钥不存入任务、报价、浏览器或报告。现有日常创作副本的原视频格式保持兼容；低成本预览可在本页单独下载，完整维护恢复仍需保留整个 data。
