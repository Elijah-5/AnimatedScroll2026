# 实验记录、截图便笺与画内分镜

## 实验操作

页眉「实验面板」可开始和结束实验。实验跨页面和项目延续，浏览器刷新后恢复。只有用户明确开始后才采集操作；结束会先同步本机队列并保存当前可保存的编辑，再冻结实验统计和最终产出。保存冲突不会改写用户内容，尚未保存的输入仍在操作记录中。

面板显示总时长、前台时长、模块进入次数／点击／输入修改／智能修改指令、操作频率、访问顺序、产出变更与前后内容、中间保存版本、截图便笺和可筛选时间线。实验面板、截图便笺分别统计停留时间，避免混入剧本、线索等制作模块。研究者可导出 ZIP、JSON、CSV；ZIP 含结构化内容、完整事件与便笺截图。视频、来源文件保留本地资源地址，不把其大文件自动复制进实验包。

- 总时长：从点击开始到点击结束，包括离开网页的时间。
- 前台时长：网页可见且窗口有焦点的时间，每五秒记录一个停留区间，跨标签页重叠区间取并集。
- 模块频率：点击与已提交输入修改的次数／该模块前台分钟数；低于一秒时不显示换算频率。
- 输入：记录字段修改前后内容、所处条目、按钮名称、发送给智能修改的指令、操作请求及保存结果；不采集每次按键或鼠标移动。
- 产出：保留开始／结束快照和被实验请求触发的中间保存内容；派生摘要缓存刷新不算新增创作内容。

事件先写入 IndexedDB，再按批次同步；事件和开始／结束请求具备幂等保护。网络失败时保留队列，可重试结束，也可导出本机待同步记录。实验结束后不再采集新操作；未确认的本机记录不会被静默删除。统计是前台停留和操作记录，不等同于认知负荷的自动测量。

密码框、隐藏字段、实验员密码请求和敏感凭据字段不记录。不会自动截图、录屏、录音或把截图交给模型。当前为文字便笺，按用户要求不增加 think-aloud 录音。

## 截图便笺

右侧浮动「截图便笺」始终出现在创作和作品体验界面；全屏和原生对话框打开时会移入当前可交互层。默认在浏览器本地渲染当前可见网页，不使用屏幕共享接口，也不弹共享授权。操作为「点击截图 → 在冻结的网页上拖框 → 松手后自动裁切并进入便笺」；文本框自动获得焦点。可用 Esc 取消，或用「截取整个可见页面」按钮代替拖框。调整窗口大小时取消旧选区，避免坐标错位。

预览只显示已经裁切的局部；需要时再点「裁切图片」继续缩小，或「重新框选网页」重拍。粘贴／导入图片默认整张可用，不要求额外选择。只有点击保存才向本站后端提交局部像素和便笺；完整网页帧仅暂存在浏览器内存中。截图工具自身和密码／标为私密的区域不进入网页截图；输入框保留当前文字，视频用当前帧，不录制。滚动坐标兼容 body 与 html 两种滚动根，防止重复偏移。

「其他截图方式」中保留选择图片和「截取其他窗口（需授权）」。浏览器原生屏幕共享权限不能永久记住，因此跨窗口方式仍由浏览器每次询问；默认网页截图不需要这项权限。网页渲染不能包含地址栏、其他应用或受保护的跨域媒体，此时可使用系统截图后粘贴，或显式选择跨窗口截图。截图失败可直接写文字便笺；保存失败保留已选局部和文字供重试。
便笺记录实验、项目、模块、实验时间点、反馈类型和文字；实验外也可保存独立便笺。开始新的截图或改用图片会使先前未完成的截图请求失效，避免迟到的授权结果覆盖用户正在编辑的反馈。

实现依据：[modern-screenshot](https://github.com/qq15725/modern-screenshot)；跨窗口截图标准：[MDN Screen Capture API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Capture_API/Using_Screen_Capture)、[W3C Screen Capture](https://www.w3.org/TR/screen-capture/)。

## 数据与接口

四张持久化表：`experiment_runs`、`experiment_events`、`experiment_artifacts`、`experiment_notes`。内容快照复用已有压缩去重存储；SQLite 和显式 MySQL 迁移均支持。服务重启前将进行中的用户实验视为活跃任务，防止例行重启打断实验。

- `POST /api/experiments/start`：幂等开始，绑定浏览器标签页和初始项目。
- `POST /api/experiments/{id}/events`：有序批量事件，重复提交不重复计数。
- `POST /api/experiments/{id}/end`：同步完成后冻结时长及产出。
- `GET /api/experiments`、`GET /api/experiments/{id}`：历史实验与统计。
- `GET /api/experiments/{id}/events`：按模块、事件类型筛选并分页。
- `GET /api/experiments/{id}/outputs`、`/versions`：最终内容与中间版本。
- `GET /api/experiments/{id}/export?format=zip|json|csv`：导出研究数据。
- `POST /api/experiment-notes`：手动保存裁切图与文字；相同请求可安全重试。
- `GET /api/experiment-notes`、`GET /api/experiment-notes/{id}/image`：便笺与局部图片。

## 沉浸式分镜

作品体验中的白色播放器卡片改为画内蒙太奇：原画缓慢聚焦选定区域，分镜视频／图像沿软边溶入画面，讲解字幕与轻量控制叠在画内。关闭时画面溶回原画全景；可上一镜／下一镜、选择连续观赏、暂停、重播和全屏。全屏中仍保留截图便笺入口。视频与图像保持比例，不拉伸填满。

已解锁分镜改为横向画带，避免多张视频播放器同时占据页面。没有生成视频时，使用原画局部与讲解，并明确标为「原画叙事 · 非生成视频」。本轮沿用 Wan 留空的决定，不启用视频模型、不提交视频任务。优先使用本地中文朗读；没有本地语音时自动按句展示文字。切换窗口会暂停播放，动效遵守减少动态效果设置。

## 验证

后端覆盖显式开始／结束、跨模块顺序与次数、前台区间去重、完整输入与敏感字段排除、实际保存链路、中间内容覆盖后仍可导出、结束后统计不变、跨项目内容、新旧请求重试、截图尺寸和 ZIP／CSV 导出。前端状态测试覆盖敏感字段清理、反向框选、原始像素映射和时长格式。浏览器验收在独立数据库与已解锁分镜测试数据中进行，不修改正式实验或创作记录。

最终验证：454 项后端测试、65 项前端状态测试通过，生产构建与 `git diff --check` 通过。1440×900 和 1920×1080 浏览器检查覆盖画内分镜、全屏便笺入口、分镜切换与回到原画；独立新会话完成开始、跨模块、结束，全部记录已同步。正式服务加载前使用 SQLite 在线备份，加载后原有数据表内容指纹未变化。

截图交互优化验证：66 项前端状态测试和生产构建通过；浏览器实测直接进入网页框选、不弹共享请求，松手后自动裁切并聚焦便笺。滚动页面与画布已对照原页面，补充滚动根回归测试。
