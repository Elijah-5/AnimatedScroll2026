# 版本与依赖规则

条目分别保存草稿、确认内容和生成依据。保存草稿不影响下游；发布上游内容后，下游保留确认与使用能力，仅提示“基于旧版本”。展开可查看具体差异，点击“已核对，继续使用”记录复核，不修改原生成依据，不要求改字或重新生成。

当前页和全项目可批量确认资料、人物对应、人物档案、设置、剧情、线索、知识和分镜。可确认项按依赖顺序在一个事务内保存；未匹配、冲突、未配置、生成中的条目列出跳过原因。历史八表、模型建议采用和AI一致性建议保留独立处理。批量确认不调用模型，不生成视频。

已确认历史版本按原依赖解析，原文引用仍须逐字核对；删除对象、缺失素材及无法恢复的依据只阻止直接涉及这些问题的新操作。普通版本提醒不计入强制待办，不阻止导出。条目草稿的撤回仍恢复最近确认内容。

内容版本、原生成依据及已复核版本分别记录。运行中输入或结果区域被修改时，结果保存为旧输入建议，不能覆盖人工编辑，不能自动重试。项目改名、无关编辑和单纯复核不会作废其他内容。

视频审核依据实际发送的文本、图片及顺序、模型和参数；资料简介等元数据变化本身不撤销审核。旧视频可播放、下载和选择，并注明来源版本。远端任务去重、重启恢复及提交不明不重提的规则继续保留。

体验会话固定创建时的内容和知识快照；普通修改后提示“正在体验旧版本”，保留聊天与线索进度，观众明确重新开始才进入最新版。体验写入不增加制作版本。

完整字段、API、迁移及验收说明见[版本提醒与一键确认](16-版本提醒与一键确认.md)。
