## 使用入口

1. 前五个制作工作区继续按原方式编辑、保存、确认及发布改动。
2. 在「分镜管理」确认分镜后，下方「独立分镜视频」查看实际提示词。修改并保存后勾选审核，点击生成。
3. 同内容重复提交复用任务。可以播放、下载、选择当前版视频用于体验；历史视频仍保留。提交状态不明时不会重复提交；确定失败时可审核后明确重试，下载失败只重新下载。
4. 顶栏「欣赏作品」选择人物，点击发送才调用实时模型。回答仅使用本人物的已确认资料与绑定线索，不读取完整剧本或其他人物聊天；没有剧情时间过滤。
5. 点击回答下的「记录线索」才解锁对应分镜。没有有效视频时展示已确认分镜。刷新恢复会话；相关确认内容变化时需明确重新开始，草稿及项目改名不重置。
6. 「检查与发布」底部检查／导出ZIP、JSON、Markdown。只导出有效确认内容，不包含密钥、未确认草稿或观众聊天。ZIP携带可用素材；离线包不提供实时模型服务。

## 配置

现有`.env`未被修改。默认`MODEL_PROVIDER=aihubmix`，继续读取原AIHUBMIX配置。添加视频用的`DASHSCOPE_API_KEY`不会自动切换文本／视觉。

视频默认沿用同学代码：`wan3.0-video`、480P、5秒、音频开启、参考图片输入、无本地次数上限；`DASHSCOPE_VIDEO_BASE_URL`可配置服务地址。原画提供风格参考，已确认出场实例的裁切提供人物参考。单张参考每边240–8000像素、比例不超过8:1、PNG编码不超过20MB；不自动裁切原画。参考图最多原画加9个人物。首尾画面描述进入文本，不提供实际首尾帧图片。

本次使用模型替身验证请求结构和状态处理，未验证云端当前模型可用性、计费或真实视觉质量。真实模型回答的语义准确性也需实际验收；ID和逐字引文校验不能替代这一判断。

如需显式切换文本／视觉到DashScope：设置`MODEL_PROVIDER=dashscope`及`DASHSCOPE_BASE_URL/DASHSCOPE_MODEL/DASHSCOPE_VISION_MODEL`，再重启。选择的服务缺少密钥会报错，不混用另一服务的密钥。

已有SQLite启动无需新增数据库服务。MySQL另需requirements中SQLAlchemy／PyMySQL；在本机复制`.env.mysql.example`为`.env.mysql`并填写自己的配置，明确选择`CREATION_DB_BACKEND=mysql`。环境文件不提交。Docker仅绑定本机3307：

```sh
docker compose --env-file .env.mysql -f compose.mysql.yaml up -d --wait mysql
```

迁移前停止应用编辑，保留整个data目录：

```sh
.venv/bin/python -m scripts.migrate_sqlite_to_mysql
.venv/bin/python -m scripts.migrate_sqlite_to_mysql --verify-only
```

工具使用SQLite backup API，复制projects、events、tasks、studio_jobs、document_cache、video_jobs、experience_sessions、experience_turns并重建五张查询投影。逐行比较原始记录与完整投影，不只核对数量。目标非空或发现未支持的源表时停止，不覆盖、不删除源数据库。真实MySQL连通与事务行为本次未做实机验收。

诊断命令均需明确运行，不在启动或浏览页面时执行：

```sh
.venv/bin/python -m scripts.check_model_access
.venv/bin/python -m scripts.check_detector
.venv/bin/python -m scripts.prepare_detector
```

第一个会发送小规模真实模型测试；后两个只运行／准备本地检测，首次可能下载官方权重。合并验收没有执行这些云端或下载操作。

## 新增接口

所有路径以`/api`开头。制作写操作携带当前项目`version`；体验写入独立表，不改变制作版本。

| 路径 | 方法和行为 |
| --- | --- |
| `/projects/{pid}/catalog` | GET，工作台资料库投影与当前状态 |
| `/database/status` | GET，实际数据库类型及连通性，不返回凭据 |
| `/projects/{pid}/archive`、`/restore` | POST `{version}`；GET `/projects?archived=true`列出归档项目 |
| `/samples/artworks`、`/samples/artworks/{sampleId}` | GET列表／POST明确创建仅导入图片的新项目，不预置人物与确认状态 |
| `/projects/{pid}/storyboards/{sid}/video-prompt` | GET编译稿、保存稿、指纹和过期状态；PUT `{version,text,baseFingerprint}`保存最终文本并撤销旧审核 |
| `/projects/{pid}/storyboards/{sid}/confirm-video` | POST `{version}`，确认当前保存文本及输入 |
| `/projects/{pid}/videos` | GET任务；POST `{version,storyboardId}`显式生成，相同请求去重 |
| 同上POST的明确重试 | 可加`retryOf`和`requestId`，仅允许当前输入的已确定失败任务；相同重试编号仍去重 |
| `/projects/{pid}/videos/{jobId}/refresh`、`/file` | POST继续原任务查询／下载；GET本地视频，支持播放器读取 |
| `/projects/{pid}/storyboards/{sid}/experience-video` | POST `{version,jobId}`，仅选择当前有效视频 |
| `/projects/{pid}/experience` | GET可交谈实例、已确认原画和内容签名，不调用模型 |
| `/projects/{pid}/experience/sessions` | POST建立体验；GET `/sessions/{sessionId}`恢复记录及已解锁媒体 |
| `/projects/{pid}/experience/sessions/{sessionId}/messages` | POST `{requestId,characterId,text}`；返回状态、回答、允许线索及服务端提取的依据 |
| `/projects/{pid}/experience/sessions/{sessionId}/collect` | POST `{turnId,clueId}`，仅接受此会话有效回答实际提供的线索 |
| `/projects/{pid}/narrative/inspect`、`/export` | GET检查／导出；format=zip/json/md，正式导出还需draft=false、reviewed=true和当前version |

`merge-backups/20261031-235253/creation-agent-demo`
