# 首次加载与群体叠卡

首次打开显示独立加载页，依次提示读取项目列表、打开作品资料、准备工作台。Vue 脚本尚未就绪时也有静态加载文字。读取失败显示具体错误与“重新加载”；重试仅重新读取，不触发生成。正常切换制作页不显示全屏加载页。

## 群体卡片

“画作与人物”将关联同一 `characterId`、且该角色 `roleType=group` 的身影合为一张叠卡。不会仅因姓名相同合并具名人物，也不新建人物体系。

- 共用角色、人物简介、来源、补充说明及审核状态集中展示，只有一个“确认此群体”按钮。
- 卡片内的编号选择各自身影，左侧画作中独立调整位置框；从画作点选也能定位叠卡。新增、删除及撤销人物框仍沿用原流程。
- 现有逐人观察、衣饰、动作与匹配依据完整保留在折叠区，不把某个实例的衣饰复制给全组。新共用说明存为 `material.draft.visualGroups[characterId]`，类型为创作备注 `creator_note`，不升级为历史事实。
- 整组确认在一个原有确认事务内审核全部 `visual:<annotationId>`、`observation:<annotationId>` 和已有共用说明。人物档案本身仍在人物档案页审核；本操作不确认其他角色。
- 重用原实例的审核记录，切换群体或具名类型不会把 AI 来源变成人工来源。新 AI 身影加入后仅重新提示该组审核；并发变更导致旧校验值失效时整组拒绝写入。
- 位置编辑、保存、确认和首次读取均不调用模型。历史、体验和视频任务不删除。
