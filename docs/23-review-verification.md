## 恢复步骤

1. 等待运行中的生成和对话完成，关闭本项目服务；先另存当前完整 `data/`，保留实施之后的新制作和聊天。
2. 源码恢复可选择实施前备份的 `project/` 或某次上线备份的 `source/`。恢复源码时保留当前 `data/` 与 `.env`；新增的分组审核JSON字段可保留，旧接口继续兼容。
3. 使用项目的启动命令重新启动，先检查项目列表、原文文件与旧聊天，再继续制作。
4. 如确需恢复制作数据，应按选定项目和快照恢复，继续保留当前体验、聊天及视频记录；**不要用实施前整库覆盖当前数据库**。

详细字段、审核单位、消费与接口规则见 [工作流说明](22-review-workflow.md)。
