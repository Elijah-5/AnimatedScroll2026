# 0 概览与工作台导航

## 入口
首页默认进入 `#/overview`，具体制作链接仍直达对应页面。概览不依赖项目存在，只介绍系统流程，不展示项目进度仪表盘。左侧制作导航为0概览、1古画资料库、2人物档案、3剧本大纲、4线索库、5分镜管理。

## 流程介绍
导入画作与资料 → 校准人物 → 创作剧情 → 整理线索 → 返回人物档案绑定知识 → 制作分镜 → 检查。

文化背景从资料整理进入线索库；人物关系从人物档案进入线索库；叙事内容从剧本大纲进入线索库。流程图和阶段卡片提供页面入口，明确线索库到人物知识的回访关系，页面可自由往返。

说明三条创作规则：人工核对确认；发布已被使用的改动前查看影响；点击明确按钮才调用模型。视频生成和互动欣赏属于后续能力。

## 界面
浅灰背景、白色工作面、深色无衬线文字及少量青绿色。固定顶栏与左侧导航，内容区域滚动；窄屏折叠导航。人物确认色及线索真实性边框仍有独立语义。

## 切页与保存

切换制作页立即显示目标页面，不自动保存、不重新读取整份项目，也不运行检查或模型。已访问页面按项目保留编辑表单、人物候选编辑、文献模式和资料视图；往返概览或欣赏作品也保留当前未保存内容。切换项目时先保存，再清除上一项目的页面缓存。离开浏览器前仍需点击「保存草稿」；保存、确认、采用和生成继续执行版本校验及并行编辑保护。

后台通过 `GET /api/projects/{pid}/studio/poll?version=n` 读取轻量版本和任务状态；只有服务端项目版本变化才返回完整项目，按原合并规则保留本地编辑。轮询不写入制作内容、不启动任务；后台标签暂停同步，分镜视频查询在离开分镜页时暂停。检查清单仅在数据或任务变化时更新，展开检查时仍可主动刷新。

## 验收
无项目可以阅读流程；默认入口、页面直达、返回创作正常；概览不启动模型任务，不增加进度仪表盘。
