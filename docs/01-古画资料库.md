# 古画资料库

## 布局
顶部为古画工作区：原图、人物框、裁切图和姓名绑定。下方为同一个「文献资料」模块，分「上传文献文件」和「输入文本」两种模式，使用同一个整理按钮和结果区。再下方是[统一作品资料库](18-统一作品资料库.md)，不再单列旧三段资料输入面板。

## 操作与模型
保留本地检测、补框、删除、撤销、缩放、平移和姓名纠正。文件上传和文本保存不调用模型；明确点击「整理资料（调用 LLM）」后，以同一文献分析任务生成摘要、人物候选、逐字依据及结构化草稿。文本模式先保存原文再整理，可与文件一同勾选；不要求事先拆成三段。视觉分析、OCR和文化线索均由各自明确按钮触发，确认资料不会隐式启动模型。失败保留原文、草稿和上游确认。

## 数据
文件和文本统一保存为 documents 与 sources，整理结果统一为 documentAnalysis（claims、people、summaries、原文位置）及同一份 material.structured 草稿。文本标题与出处可选，未知信息留空；新文本以文献原文保存，编辑同一文本保留文献及来源 ID 并增加来源版本。旧版本文件和确认依据保留，重复保存相同内容不重复建文献。

原三段文字保留在「当前已采用的制作摘要／原有资料」折叠区，可复制到文本输入，原文字与出处不覆盖。新整理摘要和人物仍需选择采用，再按原资料确认规则发布。人物实例与资料角色分开，保留稳定 ID。

作品资料库的「人物与关系」包含人物关系图，读取统一关系及现有关系线索。箭头保留方向，草稿与已确认关系分开标记；同一关系保留多个来源，点击查看逐字依据，角色节点进入同一人物档案。群体共用节点并显示实例数，画外关系人物需明确勾选显示。

## 校准与验收
人物框自动显示裁切图；面部框由明确触发的视觉分析建议，用户可独立调整。不可见时回退人物裁切并标明。需要保存和确认的条目走统一版本规则。验证缺图、无资料、OCR错误、未知身份及零次隐式LLM调用。

本地检测使用全图和多尺度重叠切片。视觉补检单独生成候选，不自动改框；用户调整和采用后，再显式点击身份匹配。匹配展示原文支持、冲突及不确定性，保留人工指定。补检、局部只读和并行编辑细则见[生成与人物识别](10-生成与人物识别.md)。

「文献资料」支持长PDF后台本地解析、按页预览、显式OCR和全文分批整理。三段摘要及明确的本画人物由用户选择采用；背景姓名只保留文献提及，原文页引用始终保留。详见[长PDF文献整理](11-长PDF文献整理.md)。
