# 生成、并行编辑与人物识别

## 任务与编辑

顶部优先显示当前任务、旋转图标、真实阶段及已用时间；任务完成后恢复首要待办。本地人物检测标为“检测中”，云端视觉任务为“分析中”，文本任务为“生成中”。模型没有提供进度时不显示估算百分比。

每个项目同时只接受一个检测或生成任务；前端禁用重复生成，后端在两个任务表之间事务性检查。任务结果区只读，其他人物、剧情、线索、配置可以编辑、保存和浏览，项目也可以改名。修改任务实际输入会显示提示，并停止后续调用；已发出的请求不能取消，但返回结果不会覆盖修改。

任务记录输入摘要及输出字段。完成时读取最新项目，仅应用生成差异；无关保存和改名不会使结果过期。前端通过基线、本地编辑和后台最新值三方合并；同一字段冲突时保留本地内容，用户选择保留本地或采用后台版本。未保存编辑仍需保存，刷新不会恢复内存草稿。

## 检测与补检

1. 点击“检测人物 · 本地模型”，在全图及多尺度重叠切片中检测，按重叠和位置去重；不因服饰相同合并人物。人工调整过的框、姓名和确认结果保留。
2. 仍有漏检时，点击“视觉补检漏检人物 · 调用 LLM”。最多检查全图和4个密集区域，可能包含多次请求。
3. 蓝色虚线仅为补检候选。先选择、删去误检或调整坐标，再点击“采用选中的框 · 不调用模型”。原有实例ID和人工确认保持不变。
4. 采用不会启动匹配。用户另行点击“分析外观并建议身份匹配 · 调用 LLM”。仍可手动补框、调整、删除及直接命名。

## 资料与身份

“整理资料与角色候选”同时提取具名人物、角色称谓及群体角色。按原文区分画中人物、背景人物和未知范围；原文的服饰、姿态、位置、邻近人物提示必须关联逐字引文。没有身份经历则留空，不补编。重新整理先查看差异，明确采用后才修改已有资料，并保留角色ID。

身份建议结合带框全图、清晰人物裁切、邻近环境及原文提示。必要条件未支持、原文明示条件冲突、把握不足或缺少有效依据时保持未匹配；支持、冲突和不确定性在卡片中展示。仅背景人物不作为默认候选；人工指定和已确认对应保留。群体角色可关联多个实例，不给配角编造名字。

《步辇图》等现有项目要使用新增称谓及身份提示，需主动重新整理资料、查看差异并采用；打开项目不会补齐或调用模型。检测框和模型身份建议始终是待核对内容。

## 项目名称

项目标题使用画作名称，同名项目依次显示“画名”“画名(2)”“画名(3)”，已有序号保持稳定。顶栏编辑按钮修改画作名称，Enter保存，Esc取消；新建时也可输入。名称保存到artworkName，列表显示title。采用文献整理结果时同步已确定的画名。改名只更新元数据和日志，不撤销确认，也不属于生成依赖。

群体角色共用一份人物档案，多个框通过characterId关联。画面标签及实例卡片显示“宫女(1)”“宫女(2)”等；编号只用于显示，基于实例列表顺序，移动框不改变编号，不写入角色姓名或生成新档案。未匹配实例保留人物编号。
