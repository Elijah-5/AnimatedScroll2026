# 一键完成与默认启用（3.4）

> 此文仅保留旧接口与历史方案记录；当前操作已改为自动保存、分组审核及当前步骤生成，见 [简化工作流](22-review-workflow.md)。

本文替代旧文档中逐次“生成、采用、保存、确认”的默认操作说明。高级手动接口继续兼容，付费视频仍单独审核实际请求并提交。

## 日常使用

上传画作，在作品资料库上传文献文件或输入文本，点击页首 **一键完成本页（调用模型）**。人物、剧本、线索、分镜各页同样操作；概览或检查面板可 **全项目一键准备**。缺少前置时后台按依赖顺序补齐。已启用前置优先复用，已有有效草稿先校验并启用，再判断是否需要模型。打开页面、切页、保存和查看不调用模型。

人物默认只编辑一段小传、自称、性格及整体角色 prompt，详细档案和知识依据折叠保留。称谓和性格选择优先于旧 prompt 中的表达设定；性格和即时反应属于演绎，不写成史实。全项目时间视角只在剧本页体验设置中选择一次，默认画中事件当时，另可选择人物生平回忆。年代不明不补编年份。

修改后点击 **保存并应用**，即可发布本次修改；不需要再次“采用、保存、确认”。显式“我已人工核对”留在高级操作中。已确认内容和手写文字保留；重生成的人设另存建议。欣赏页支持继续旧会话、直接进入已准备的内容、一键准备并进入最新版；最新版会建立新会话，保留旧聊天和线索。

没有已知线索的角色可以按身份问候、自我介绍，范围外自然说明不知情。只有点击发送才调用聊天模型；点击记录线索才解锁分镜。资料、推断和演绎三类段落规则继续适用。

## 可用性与来源

- `published/revision` 继续表示可供管线消费的不可变版本，不等于人工审核。
- `activation.method=auto`：AI默认 · 已启用；保留流程编号和启用版本。
- `activation.method=manual`：人工编辑 · 已启用，不自动声明人工逐字核对。
- `activation.method=human`：明确点击人工核对；旧确认记录继续有效，不要求补手续。
- 记录 `manualFields` 和 `autoValues`：只有空字段、未被人工修改的旧默认值可自动更新。旧事件中可恢复的手动编辑字段也纳入保护。
- 时间分类、来源类别及论文转引身份保留。`knowledgeTiming.access=assumed` 是AI推定知晓；明确后续、被排除或越权的知识不进入当时对话。
- 人物群体多个画中实例仍共用一个 characterId、人设和知识；画面实例ID不合并。自动身份解释单独标注，其他解释和逐字依据不删除。
- 发布更新产生版本提醒，保存草稿不传播提醒；旧人设及体验继续解析原依据。视频仅实际文本、图片内容/顺序或参数变化时重新审核。

缺失图片、文件损坏、无效引用或版本冲突明确指出条目。单条校验不通过会跳过并说明，其他有效角色继续可用；全局必要输入缺失会停止依赖该输入的步骤。普通争议、缺失档案字段、AI建议和旧版本提醒不要求人工逐项签字。

## 后台接口与恢复

`POST /api/projects/{pid}/studio/completions` 接收 `version/requestId/page`；page 为 library、characters、outline、clues、storyboards、experience 或 all。返回任务编号，不等待生成完毕。任务放在原 studio_jobs 表，family=completion，记录每阶段输入摘要、模型、提示词版本、结果版本、输出校验值和状态。

`GET .../completions/{id}` 返回阶段进度、跳过原因和可交谈角色/分镜数量。`POST .../{id}/continue` 与 `cancel` 接收 version/requestId，幂等且受版本校验约束。取消保留已完成阶段；继续复用完成阶段，有新的人工编辑则重新核对所涉及阶段。相同请求编号不启动第二次生成；新请求对已完成内容仅补缺项。

模型调用期间不持有数据库事务，每阶段成功后在原项目版本事务内保存。每个分镜单独保存和启用，后续镜头失败不丢失已有结果；已完成生成输出按输入、模型及提示词版本写入持久化缓存，应用失败后也可复用。输入或结果区域被并行修改时，保留人工内容，旧输入结果放检查面板建议区。服务重启把运行任务标记中断，不自动重发未知请求；只有用户明确继续才重做未完成阶段。任务状态复用轻量轮询，切页不取完整项目、不调用模型。历史事件审核回放仅在显式任务内进行。

`POST /studio/apply` 接收 version/keys，按依赖顺序在一次项目写入中应用手动修改。旧 draft/confirm 接口保留。

## 模型和验收预算

来源提取仍使用 AIHUBMIX_MODEL；视觉仍使用 AIHUBMIX_VISION_MODEL；密钥不变。新增可选 AIHUBMIX_DEFAULTS_MODEL（人设及创作方向默认值）、AIHUBMIX_DIALOGUE_MODEL（实时聊天），未填沿用原文本模型。DashScope 有同名目的配置，但本次未连通验收。

本次真实验收使用项目和所有素材副本，所有请求共用一个加锁持久化账本：最多60次，保守预算最多1美元，按10人民币/美元的预算换算上限10元。该换算只用于预算保护，不代表实际汇率。每次请求按UTF-8字节、图片上限和最大输出预留费用；采用高于供应商公示的费率，不假设缓存折扣。未知费用保留全部预留金额，不自动重提、不追加预算，不调用收费工具或付费视频。

重现入口：`.venv/bin/python scripts/oneclick_acceptance.py --live --run /private/tmp/scroll-oneclick-live-20261101`；继续验收必须使用同一目录及账本，不能另建账本绕过总限额。`--compare-only` 仅重复同题模型对比，也计入同一预算。价格参考：[Qwen3.7 Plus](https://aihubmix.com/model/qwen3.7-plus)、[当前 DeepSeek](https://aihubmix.com/model/deepseek-v4.1-flash-1017)。实际成绩与费用见本次验证记录。
