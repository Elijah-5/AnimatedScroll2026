# 听乐片段演示

资料及画作核对入口：https://www.dpm.org.cn/collection/paint/228200.html

点击工作台「载入示例」，得到人工编写的待审核草稿。本例将一个听乐片段拆成「落座 → 弦间 → 余音」三个叙事节拍，并不声称这是画作原有的三个段落。

推荐演示：

1. 展开资料，说明这是人工阅读笔记，核对馆方出处。
2. 进入人物档案，检查四名角色及角色知识，逐个确认并保存。
3. 进入大纲，说明三场是创作组织方式，确认后保存。
4. 进入审核，查看「落座」的依据关联，批准；切换「弦间」，说明对白为虚构。
5. 将对白改成「有依据」并尝试批准，系统应拦截，因为资料没有这段对白的直接记录。
6. 恢复「虚构补充」，批准。修改一个单元后展示批准失效和重新审核。
7. 有模型密钥时，提出局部重写，展示提案比较和锁定保护，再检查与正式导出。
8. 无密钥时可演示编辑和草稿导出；不能将人工案例或模拟测试作为真实模型联调结果。

结构化草稿示例见 `story-package.json`。资料整理与虚构故事均可修改，但更改依据需要重新核查相关内容。
